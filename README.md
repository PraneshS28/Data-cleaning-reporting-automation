# Data Cleaning & Reporting Automation

## Project Overview
This project focuses on cleaning and organizing raw Excel data to improve data quality, consistency, and accuracy. The objective is to automate and simplify the data-cleaning process and make the dataset ready for analysis and reporting.

## Tools Used
- Microsoft Excel
- Excel Formulas
- Data Cleaning Techniques

## Project Files

| File Name | Description |
|---|---|
| `Data Cleaning Start.xlsx` | Original raw dataset before cleaning |
| `Data Cleaning Completed.xlsx` | Cleaned and organized dataset after processing |

## Data Cleaning Activities Performed

1. **Removed Unnecessary Spaces:** Cleaned extra spaces from client names and contact names.
2. **Standardized Text:** Improved consistency in text formatting.
3. **Handled Missing Values:** Identified missing values in Payment and Revenue columns and replaced them with `NA`.
4. **Separated Columns:** Split Department and Region information into separate columns.
5. **Updated Formulas:** Used the `IFERROR` function to calculate Profit Margin and handle calculation errors.
6. **Improved Data Structure:** Organized the dataset into a cleaner and more consistent format.

## Expected Outcome

- Better data organization.
- Reduced manual data-cleaning effort.
- Prepared the dataset for further analysis and reporting.
